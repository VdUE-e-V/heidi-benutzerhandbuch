# Mitmachen

Das Benutzerhandbuch lebt davon, dass Nutzerinnen und Nutzer es verbessern. Du hast einen Fehler gefunden, eine Anleitung ist unklar oder es fehlt etwas? Dann freuen wir uns über deine Hilfe.

## Etwas korrigieren

Auf jeder Seite findest du oben rechts ein **Stift-Symbol**. Damit öffnest du die Seite auf GitHub und kannst deine Änderung direkt vorschlagen. Dafür brauchst du ein kostenloses GitHub-Konto. Das HEiDi-Team prüft jeden Vorschlag, bevor er veröffentlicht wird.

Wie du größere Änderungen machst und welche Schreibregeln gelten, steht in der [Anleitung für Mitwirkende](https://github.com/VdUE-e-V/heidi-benutzerhandbuch/blob/main/CONTRIBUTING.md).

## Ohne GitHub

Schreib uns einfach eine E-Mail an [info@hilfeapp.org](mailto:info@hilfeapp.org) mit dem Link zur Seite und deinem Vorschlag.

## Fehler in der App

Fehler in der App selbst – nicht im Benutzerhandbuch – meldest du bitte unter [heidi-issues](https://github.com/VdUE-e-V/heidi-issues) oder in der App unter **Einstellungen › Unterstützung bei Problemen**.
