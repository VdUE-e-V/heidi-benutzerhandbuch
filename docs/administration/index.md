# Für Administratoren

Diese Kapitel richten sich an Organisationen, die HEiDi auf einem **eigenen Server** betreiben möchten – zum Beispiel, weil sie besonders sensible Einsatzdaten verarbeiten oder die volle Kontrolle über ihre Daten behalten wollen.

Für die meisten Nutzerinnen und Nutzer ist das nicht nötig: Der **HEiDi Standardserver** des VdUE steht allen kostenlos zur Verfügung.

- **[Eigenen Server betreiben](eigener-server.md)** – Laufzeitumgebung einrichten: Apache als Reverse Proxy, HTTPS, Firewall und Datenbank.

!!! info "Unterstützung"
    Du planst einen eigenen Server? Melde dich vorab beim HEiDi-Team unter [info@hilfeapp.org](mailto:info@hilfeapp.org) – wir helfen bei der Einrichtung.
