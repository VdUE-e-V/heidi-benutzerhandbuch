# Glossar

Aktives Paket
:   Das eine Paket, mit dem du gerade arbeitest. Es bestimmt Einsatzformular, Stichwörter, Checklisten, Material und Kontakte.

Algorithmus
:   Ein Entscheidungsbaum in einem Handbuch, der dich mit Fragen Schritt für Schritt durch eine Situation führt.

Archiv
:   Reiter im Bereich **Einsätze**, in dem abgeschlossene Einsätze liegen.

Basis-Paket / Basis-Handbuch
:   Vorlage des VdUE, zum Kennenlernen und als Ausgangspunkt für eigene Pakete und Handbücher.

Benutzerhandbuch
:   Dieses Nachschlagewerk. Nicht zu verwechseln mit den **Handbüchern** in der App.

Checkliste
:   Ein fester Ablauf zum Abarbeiten im Einsatz, mit Häkchen, Auswahl- und Textfeldern.

Einsatzstichwort
:   Kurzbeschreibung des Einsatzes, z. B. „Offene Wunde / Blutung“. Steuert, welche Inhalte die Einsatzübersicht zeigt. Ein Einsatz kann mehrere Stichwörter haben.

Einsatzübersicht
:   Die zentrale Ansicht eines Einsatzes, gegliedert in Abschnitte wie Vorbereitung, Einsatz und Nachbereitung.

Handbuch
:   Sammlung von Wissen in der App: Artikel, PDF-Dokumente und Algorithmen. Du kannst mehrere gleichzeitig aktivieren.

HEiDi
:   Hilfeapp für Einsatzdienste.

HEiDi-Editor
:   Verwaltungsprogramm im Browser, mit dem Pakete und Handbücher erstellt werden.

Lage
:   Bündelt mehrere zusammengehörige Einsätze, z. B. bei einem mehrtägigen Katastrophenschutzeinsatz.

Paket
:   Bringt die Funktionen der App mit. Kann frei verfügbar oder passwortgeschützt sein.

Server
:   Wo dein Account sowie die Pakete und Handbücher liegen. Standard ist der **HEiDi Standardserver**; Organisationen können einen eigenen Server betreiben.

Startprotokoll
:   Liste der Prüfungen, die HEiDi beim Start durchführt. Hilfreich bei der Fehlersuche.

VdUE e.V.
:   Verein zur digitalen Unterstützung von Einsatzdiensten e.V., Träger von HEiDi.
